# Xero Documentation Index

Start here. The documentation includes:
- `overview.md` — project documentation overview.
- `structure.md` — file/folder layout and where to find things.
- `objects.md` — important object list and tips.
- `assets.md` — sprites, sounds and rooms inventory notes.
- `systems/` — deep dives for major systems.
- `CONTRIBUTING.md` and `TODO.md` — contribution and tasks.

If you want an automated CSV dump of object names and top-of-file content to aid exploration, request it and I will generate it into `docs/` (it won't touch your GameMaker assets).
