If you want to make a game using this project, you can easily,
just by modifying sprites and the Create Event variables.
Also check out the obj_sign Creation Code in the Room Editor.
>> The level of experience you need is between BASIC and INTERMEDIATE <<




FORM OF CODE STRUCTURE:


/*-----------------------------------------------------

-----------------------------------------------------*/

// TITTLE

if place_meeting(x, y, obj_par_player)
{
	// comment 2
	if (lived) //comment3
	{
		// comment 4
		example(true); //comment5
	}
}



TIP: When the game is compiled, all code spaces and comments are removed in the final executable :)

There is an object called obj_debugger, it serves to monitor some things and also to report bugs
automatically in the project. If you don't want this, just destroy the object.
